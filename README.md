# 🚦 Traffic Signal Timer

An automated traffic signal control system that manages traffic lights through predefined time intervals. The project demonstrates the fundamentals of timer-based automation and sequential traffic signal operation.

![Traffic Signal Timer Demo](Demo.gif)

## 📌 Project Overview

The Traffic Signal Timer is designed to automate the operation of traffic lights using a fixed-time control mechanism. It sequentially controls Red, Yellow, and Green signals to regulate vehicle movement and demonstrate the basic principles of automated traffic management.

## 🎯 Objectives

- Automate traffic signal operations using predefined time intervals.
- Demonstrate sequential switching between traffic light states.
- Understand the practical application of timers and electronic components.
- Explore the fundamentals of traffic management automation.

## ⚙️ Working Principle

The system operates through a predefined timing sequence:

| Traffic Light | Function |
|---|---|
| 🔴 Red | Stops vehicles and allows cross traffic to move. |
| 🟢 Green | Allows vehicles to proceed. |
| 🟡 Yellow | Provides a warning before the signal changes. |

When the timer for a particular signal expires, the system automatically transitions to the next signal state, maintaining an organized sequence of traffic light operations.

- Timer / Microcontroller
- Red LED
- Yellow LED
